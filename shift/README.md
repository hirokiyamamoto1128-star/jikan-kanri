# シフト表（Firebase + GitHub Pages 版）

店舗ごとのパスワードでログインして使う、シフト作成・人件費管理アプリです。
画面は GitHub Pages、データとログインは Firebase（Google の無料サービス）で動きます。

- 管理者パスワード：シフト作成、人件費、名簿、スキル、28時間管理、月間・年間管理、設定
- アルバイト用パスワード：シフト提出と完成シフトの確認だけ（時給・人件費は見えません）
- パスワードの確認は Firebase のサーバーが行います。データは店舗ごとに分かれ、ログインしていない人や他店舗からは読めません。

## 手順1　Firebaseのプロジェクトを作る（約5分）

1. https://console.firebase.google.com を開き、Googleアカウントでログイン
2. 「プロジェクトを作成」→ 名前（例：`gindaco-shift`）→ Googleアナリティクスはオフでよい → 作成
3. 左メニュー「構築」→ **Authentication** →「始める」→「ログイン方法」で **メール / パスワード** を有効にして保存
4. 左メニュー「構築」→ **Firestore Database** →「データベースを作成」
   - ロケーション：**asia-northeast1（東京）**
   - 「本番環境モード」で開始

## 手順2　接続設定をコピーする

1. Firebaseコンソール左上の歯車 →「プロジェクトの設定」→ 下の「マイアプリ」で **</>（ウェブ）** を押す
2. アプリ名（例：shift）を入れて登録（Hostingのチェックは不要）
3. 表示された `const firebaseConfig = { ... }` の `{ ... }` の中身を、`firebase-config.js` の `{ }` の中にそのまま貼り付けて保存

## 手順3　データを守るルールを入れる

1. Firestore Database →「ルール」タブ
2. 中身をすべて消して、`firestore.rules` の中身を貼り付け →「公開」

## 手順4　GitHub Pagesに載せる

1. GitHubで新しいリポジトリを作成（例：`shift`、Public でOK。データは入らないので公開しても大丈夫です）
2. 「uploading an existing file」から `index.html` `firebase-config.js` `firestore.rules` `README.md` をドラッグして「Commit changes」
3. リポジトリの Settings → Pages →「Branch」を `main` / `(root)` にして Save
4. 1〜2分後、`https://hirokiyamamoto1128-star.github.io/shift/` で開けます

## 手順5　店舗を作って、今までのデータを取り込む

1. 開いたページの下にある「新しい店舗を登録する」を開く
   - 店舗名：東銀座店　／　店舗ID：`higashiginza`
   - 管理者パスワード：`gsp1010967`　／　アルバイト用パスワード：`gsp0000000`
2. 「店舗を作る」を押すと、そのまま管理者としてログインします
3. 「設定」タブ →「バックアップ」→「ファイルから取り込む」で `backup_higashiginza_20261010.json` を選び →「取り込む」
4. 入力タブで 10/12〜10/13 のシフトと名簿が入っていれば完了です

## 毎日の使い方

- **店長**：管理者パスワードでログイン。スマホ・iPad・PCどれでも同じデータを見られます
- **アルバイト**：アルバイト用パスワードでログイン → 名前を選ぶ → 週ごとに提出。提出はシフト表に自動で入ります
- **印刷**：完成シフト →「A4印刷用」→「印刷する」（用紙 A4・横、余白なし）
- **バックアップ**：月に1回、設定 →「バックアップを書き出す」でJSONをPCに保存しておくと安心です
- 電波が切れても入力でき、つながったときに自動で保存されます

## 店舗を増やすとき

管理者でログイン → 設定 →「新しい店舗を追加」。店舗ごとに別のパスワードを決めます。
ほかの店舗と同じパスワードは使えません（ログイン時にパスワードだけで店舗を見分けるため）。

## 料金について

Firebaseは無料プラン（Spark）で始められ、1店舗〜数店舗の利用なら通常は無料の範囲に収まります。
アプリは「前年の1月1日以降」のデータだけを読み込むようにして、読み込み回数を抑えています（それより古い年は月間・年間画面に出ません）。
無料枠の細かい上限は Firebase の料金ページで確認してください。

## 注意

- パスワードを忘れると、その役割ではログインできなくなります。管理者パスワードは必ずどこかに控えておいてください
- アルバイト用パスワードは全員共通なので、退職者が出たら設定タブから変更してください
- `firebase-config.js` の値は公開されても問題ない種類のものです。データは手順3のルールで守られています
