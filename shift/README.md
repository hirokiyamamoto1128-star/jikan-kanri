# シフト表

シフト作成・人件費管理のWEBアプリです。
URL：https://hirokiyamamoto1128-star.github.io/jikan-kanri/shift/

## はじめて使うとき

1. 上のURLを、いつも使う端末（店のPC・iPadなど）で開く
2. 「新しい店舗を登録する」で、店舗名・店舗ID・管理者パスワードを入れて「店舗を作る」
3. 今までのデータがあれば、設定タブ →「バックアップ」→「ファイルから取り込む」でJSONファイルを選ぶ
4. ホーム画面に追加しておくと、アプリのように開けます
   - iPhone / iPad：Safariの共有ボタン →「ホーム画面に追加」
   - PC（Chrome / Edge）：アドレスバー右の「インストール」マーク

## データの保存について

- データは**その端末のブラウザの中**に保存されます。ネットがなくても使えます
- ほかの端末とは共有されません。端末を変えるときは、バックアップを書き出して新しい端末で取り込みます
- ブラウザの「閲覧データを削除」をするとデータも消えます。**月に1回はバックアップを書き出してください**（30日たつと画面上でお知らせします）

## スマホとPCなど、複数の端末で共有したくなったら

`firebase-config.js` に Firebase の設定を入れると、自動で共有版に切り替わります（店舗の作り直しとバックアップの取り込みが必要）。
Firebase側の準備は `firestore.rules` の内容をFirestoreのルールに貼るなど数ステップです。必要になったら相談してください。

## ファイル

| ファイル | 役割 |
|---|---|
| index.html | アプリ本体 |
| local-db.js | この端末に保存する仕組み |
| firebase-config.js | 共有版にするときだけ使う設定（今は空のまま） |
| firestore.rules | 共有版のデータを守るルール |
| sw.js / manifest.webmanifest / icon-*.png | ネットなしで開く・ホーム画面アイコン |

アプリを更新したときは、`sw.js` の `VERSION` を1つ上げてください（古い版が残らないように）。
