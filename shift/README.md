# シフト表（完成版 1.1）

銀だこハイボール横丁 東銀座店のシフト作成・人件費管理WEBアプリです。
URL：https://hirokiyamamoto1128-star.github.io/jikan-kanri/shift/

アプリの中の「マスタ → 使い方」にも同じ内容があります。

## はじめに1回だけ

1. URLを開き、「新しい店舗を登録する」で店舗名・店舗ID・管理者パスワードを入れる
2. マスタ → 設定 →「ファイルから取り込む」で今までのデータ（バックアップJSON）を取り込む
3. マスタで登録・確認
   - 名簿：スタッフ・時給・交通費、留学生のチェック、社員の勤務ルール（週の出勤日数・基本の時間）
   - スキル：ポジションごとのレベル（0できない〜3リーダー）
   - 設定：目標人件費率・理想人件費（曜日別）、ポジション、休憩・残業のルール
4. ホーム画面に追加（iPhone/iPad：Safariの共有 →「ホーム画面に追加」、PC：アドレスバーの「インストール」）

## 毎週の流れ

1. **希望入力**：スタッフを選び、LINEの希望を1週間分入れて「登録して次の人へ」
   - 社員：「出勤（固定）」＝決め打ち、「休み希望」
   - アルバイト：「固定」を押した日は決め打ち
2. **シフト作成**：社員シフトを自動作成 → 売上予算・理想人数 → 週全体を目標に合わせる → 28時間を調整 → ポジション・休憩
3. **希望との違い**：理由を確認し、「本人に送るLINE文をコピー」
4. **完成シフト**：確認・A4印刷・PDF保存
5. **評価**（集計 → 評価）：日・週・月を100点で採点し、改善点を表示
6. **日曜**：集計 → 社員勤務時間の「社員の残業・深夜（週）」で残業代・深夜手当を計算し「入力用にコピー」

- 新人：名簿で「新人」にチェック → 全画面に印、自動配置で一人前以上と組む
- ヘルプ（他店へ）：ポジション「ヘルプ」＋行き先 → 自店の人件費・人員に含めない（本人の28時間・残業には含める）

## 自動作成・調整の優先順位

1. 決め打ち（固定）は動かさない
2. 社員の休み希望
3. 留学生は、どの連続7日間でも28時間以内（月をまたいでも）。28時間ギリギリまで入れる
4. 時間帯ごとの理想人数を下回るカットはしない／ポジションを空にしない
5. 目標人件費率に近づける（届かなければ止めて不足額を表示）

## 計算ルール（元のスプレッドシートと同じ）

- 休憩：勤務6時間以上で0.5時間、8時間超で1時間
- 人件費：時給×労働時間（8時間を超えた分は1.25倍）＋有給の時間×時給
- 深夜：22時〜翌5時
- 28時間：労働時間（休憩を除く）。有給を含めるかは「集計 → 有給」で切り替え

## データの保存

- データはこの端末のブラウザに保存されます。ページを更新しても消えません
- ブラウザの閲覧データを削除すると消えます。**月に1回「バックアップを書き出す」**（30日たつと画面でお知らせ）
- スマホとPCで共有したいときは `firebase-config.js` に Firebase の設定を入れると共有版に切り替わります（`firestore.rules` をFirestoreのルールに設定）

## ファイル

| ファイル | 役割 |
|---|---|
| index.html | アプリ本体 |
| local-db.js | 端末に保存する仕組み |
| firebase-config.js | 共有版にするときの設定（今は空） |
| firestore.rules | 共有版のデータを守るルール |
| sw.js / manifest.webmanifest / icon-*.png | オフライン・ホーム画面アイコン |

アプリを更新したら `sw.js` の `VERSION` を1つ上げてください。
